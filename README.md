# Python Learn - Free Interactive Python Course

A free Python course inspired by Mimo (mimo.org). Learn Python step by step with interactive lessons and guided projects.

## Course Structure (Mimo-style)

| # | Lesson | Type |
|---|--------|------|
| 1 | Creating variables | Learn |
| 2 | Using variables | Learn |
| 3 | True and False | Learn |
| 4 | Equality and verification | Learn |
| 5 | Format strings | Learn |
| 6 | Python basics | Practice |
| 7 | Bot - Part 1 | Guided Project |
| 8 | Comparing numbers | Learn |
| 9 | Comparing strings | Learn |
| 10 | Discovering types | Learn |
| 11 | Types and comparisons | Practice |
| 12 | Input | Learn |
| 13 | Bot - Part 2 | Guided Project |

## Optional Projects

1. **Lunch Party Organizer** - Manage guest lists and food preferences
2. **School Grades Program** - Process student grades and create reports

## How to Run

```bash
cd python-learn
python python_learn.py
```

## Run Projects

```bash
cd python-learn/projects
python guided_projects.py
```

## Features

- 13 interactive lessons with exercises
- Guided projects (Bot conversation)
- Practice sections
- Score tracking and streak system
- Quick quiz mode
- Statistics

## Requirements

- Python 3.6+
