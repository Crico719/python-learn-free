# PYTHON LEARN - Free Python Course

Learn Python step by step with interactive lessons and exercises.

## How to run

```
cd python-learn
python python_learn.py
```

## Course structure

12 lessons covering:
- Variables, types, operators
- Conditionals and loops
- Lists, functions, strings
- Dictionaries, files, error handling
- List comprehensions

## Projects included

- Number guessing game
- To-do list
- Calculator
- Rock Paper Scissors
