# 🐍 Python Learn - Curso Interactivo Gratuito de Python

Un curso gratuito de Python inspirado en Mimo (mimo.org). Aprende Python paso a paso con **90 lecciones interactivas** y proyectos guiados.

## 📚 Estructura del Curso (Estilo Mimo)

Cada lección tiene **temas** con **subtemas** para que aprendas de forma progresiva.

| Sección | Lecciones | Tipo |
|---------|-----------|------|
| **1. Variables, Booleanos, Strings** | 1-13 | Variables, Tipos, Entrada, Bot |
| **2. Condicionales y Bucles** | 14-31 | If/Else, While, For, RPS |
| **3. Listas** | 32-46 | Listas, Proyecto To-Do |
| **4. Funciones** | 47-59 | Funciones, Sistema de Pedidos |
| **5. Tuplas, Diccionarios, Sets** | 60-71 | Estructuras de datos, Draw a Card |
| **6. Módulos y Dependencias** | 72-81 | Import, pip, Calculadora |
| **7. Errores y Excepciones** | 82-90 | Try/Except, Sensor Validator |
